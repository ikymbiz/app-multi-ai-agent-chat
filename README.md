# AI Web Studio Pro 2026

## 概要・説明
**AI Web Studio Pro 2026** は、ブラウザ上で完結する次世代のAI駆動型Webアプリケーション開発・アシスタントツールです。1枚のHTMLファイルで動作しながら、高度なAIチャット、コードの自動生成、ローカルドキュメントを用いたRAG（検索拡張生成）、そして複数ステップのAIパイプライン構築機能を備えています。

主要なLLM（Gemini, Claude, OpenAI, Grok）をシームレスに切り替えて対話ができるほか、生成されたHTML/CSS/JSコードを直接GitHubへデプロイ（GitHub Pages公開）する機能も統合されており、アイデア出しからプロトタイプ開発、公開までをワンストップで実現します。

## 主な機能一覧

* **マルチLLMチャット＆役割管理**
  * Google Gemini, Anthropic Claude, OpenAI GPT, xAI Grokの主要APIをサポート。
  * 「プログラマー」「コンサルタント」など、システムプロンプトによる役割（ロール）のカスタマイズ機能。
* **AIコード生成**
  * チャットで合意した要件に基づき、ワンクリックでHTML/CSS/JS統合ファイルのコードを生成。
  * バックグラウンド（Service Worker/Web Worker）での非同期生成に対応。
* **高度なRAG（ドキュメント検索エンジン）機能**
  * PDF、画像、Markdown、CSV、HTMLなどのファイルをブラウザ上でチャンク化＆ベクトル化。
  * BM25とコサイン類似度を用いたハイブリッド検索、さらにLLMによるリランキングで高精度な回答を生成。
  * 回答には参照元ドキュメントの出典とプレビューを表示。
* **AIパイプライン構築**
  * 「要件定義 → コード生成 → レビュー → 修正」といった複数のAI実行ステップをGUIで連結可能。
  * 前のステップの出力結果を変数として次のステップへ引き継ぐ自動化フローを構築できます。
* **GitHub連携（インポート＆デプロイ）**
  * GitHubリポジトリからのファイルインポート。
  * 生成したコードを新規・既存リポジトリへ直接コミット＆プッシュ。
  * GitHub Pagesの自動有効化により、ワンクリックでWebサイトを公開。
* **リッチな入力・ファイル添付**
  * カメラ、ギャラリー、ローカルファイルからのマルチモーダル入力（画像・テキスト解析）に対応。

## 使用技術・ライブラリ

本プロジェクトはビルド環境を必要とせず、ピュアなWeb技術とCDN経由のライブラリで構成されています。

* **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
* **データベース**: [Dexie.js](https://dexie.org/) (IndexedDBラッパー) - 設定、RAGインデックス、パイプラインのローカル保存
* **マークダウン処理**: [marked.js](https://marked.js.org/), [DOMPurify](https://github.com/cure53/DOMPurify)
* **ドキュメント解析**: [PDF.js](https://mozilla.github.io/pdf.js/) (PDF読み込み)
* **コードエディタ**: [CodeMirror 5](https://codemirror.net/5/)
* **非同期処理**: Web Workers, Service Workers
* **AI API (クライアントサイド通信)**: Gemini API (埋め込み・画像解析・推論), Claude API, OpenAI API, xAI API

## セットアップ・使い方

### 1. 起動方法
サーバーの構築や依存パッケージのインストールは不要です。
ダウンロードした `index.html`（またはこのHTMLコードを保存したファイル）を、Google ChromeやSafariなどのモダンブラウザで開くだけで起動します。

### 2. 初期設定（APIキーの登録）
AI機能を利用するために、各プロバイダーのAPIキーを設定します。
1. 画面下部のナビゲーションバーから **「⚙️ SET (設定)」** タブを開きます。
2. **「🔑 認証・キー」** セクションに移動します。
3. 使用したいAI（Gemini, Claude, GPT, Grok）のAPIキーを入力します。
   * ※RAG（ドキュメント読み込み）のベクトル化機能を利用する場合は **GeminiのAPIキー** が必須となります。
4. 画面最下部の **「設定を保存」** ボタンをクリックします。

### 3. 基本的な使い方

#### Webアプリのコードを生成する (CHATタブ)
1. **「💬 CHAT」** タブを開きます。
2. メッセージ入力欄に「ダークモードのTodoアプリを作りたい」などの要件を入力し、紙飛行機ボタンで送信します。
3. AIと対話して仕様を固めます。
4. 仕様が確定したら、チャットの吹き出しに表示される **「⚡️ コードを作成 (BUILD)」** ボタンをクリックします。
5. バックグラウンドでコードが生成されます。

#### 独自のドキュメントについてAIに質問する (RAGタブ)
1. **「📚 RAG」** タブを開きます。
2. 画面上部のドロップゾーンにPDFやテキスト、画像ファイルをドラッグ＆ドロップ（または追加ボタンから選択）します。
3. ブラウザ内でインデックス化（ベクトル化）が完了するのを待ちます。
4. 下部の入力欄から、読み込ませた資料に関する質問を送信すると、AIが出典付きで回答します。

#### パイプラインを実行する
1. **「⚙️ SET」** タブの **「🔗 パイプライン」** メニューで、実行したいパイプラインの「デフォルト設定」ボタンを押します。
2. **「💬 CHAT」** タブに戻り、入力欄の左側にある **「▶ (パイプライン実行)」** ボタンをクリックします。
3. 設定されたステップ（例：要件定義→コード生成→品質評価）が順番に自動実行されます。

#### GitHubへデプロイする
1. **「⚙️ SET」** タブの下部設定で、権限（repoスコープ）を持った `GitHub Personal Access Token` を入力・保存します。
2. コード生成完了後などに表示されるデプロイメニューから、リポジトリの作成・選択を行います。
3. 「GitHub Pagesを有効にして公開する」にチェックを入れてデプロイを実行すると、数分後に公開URLが発行されます。
